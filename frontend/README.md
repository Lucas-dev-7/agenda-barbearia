# Painel Angular

O painel é a interface administrativa do Agenda sem Furo. Para instalar as dependências e iniciar a aplicação, siga o guia da raiz do repositório: [`../README.md`](../README.md#como-executar-localmente).

O servidor de desenvolvimento usa `proxy.conf.json` para encaminhar `/api` e `/actuator` ao back-end Spring Boot em `localhost:8080`.
